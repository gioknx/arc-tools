Instalar / Atualizar Script

Passos para configurar:

  1. Instale a extensão Tampermonkey no seu navegador.
  2. Clique no botão acima para abrir a instalação do script ARC Ledger.
  3. No site do Pioneer ou Daxus, abra o painel do script e clique na aba Config (⚙ Config).
  4. No campo Usuário do Dashboard, digite o seu nome de usuário (caso seja operador) e salve.
  5. Clique em Sincronizar Histórico Completo se quiser carregar as transações antigas de uma vez só.
